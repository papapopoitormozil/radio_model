# Модель распространения радиоволн

Скрипт `main.py` рассчитывает свободнопространственные потери, дифракцию на одиночном препятствии и несколько условных сценариев потерь в материале. Все результаты являются математическими расчётами, а не физическими измерениями.

## Требования

- Python 3
- Дополнительные библиотеки не нужны: используются только `math` и `csv` из стандартной библиотеки Python.

## Запуск

Откройте терминал в папке со скриптом и выполните:

```bash
python main.py
```

Если команда `python` не найдена, попробуйте `python3 main.py`.

## Что рассчитывается

- FSPL для частот 900, 2400 и 5800 МГц и расстояний от 0,1 до 10 км;
- параметр дифракции и потери для препятствия на середине трассы длиной 1 км при 2,4 ГГц;
- условные дополнительные потери материала 0, 6 и 15 дБ на частоте 2,4 ГГц и расстоянии 10 м.

Значения 6 и 15 дБ заданы для сравнения сценариев. Они не являются справочными потерями конкретного материала или стены.

## Файлы результатов

После запуска в текущей папке появятся три таблицы CSV:

- `fspl_results.csv` — свободнопространственные потери для каждой пары «частота — расстояние»;
- `edge_results.csv` — высота препятствия, параметр ν и дополнительные дифракционные потери;
- `material_scenarios.csv` — условные потери материала, суммарные потери и расчётная мощность приёма.

CSV-файлы можно открыть в табличном редакторе. Повторный запуск перезаписывает одноимённые файлы результатов.

## Используемые модели

Свободнопространственные потери рассчитываются по формуле

```text
L_FS = 32,44 + 20·lg(f_МГц) + 20·lg(d_км), дБ
```

Для дифракции используется приближение одиночного «ножевого края» ITU‑R P.526. Свободнопространственная формула соответствует рекомендации ITU‑R P.525. Описание влияния строительных материалов приведено в ITU‑R P.2040; заданные в скрипте 6 и 15 дБ являются только условными сценарными параметрами.
